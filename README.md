# 🐾 Petlife Clínica

Projeto web para uma clínica veterinária fictícia, desenvolvido com **HTML5**, **CSS3** e **JavaScript** durante o curso da **OneBit**.

O objetivo do projeto é praticar desenvolvimento front-end, estruturação de páginas, estilização, organização visual e pequenas interações com JavaScript.

---

## 🌐 Acesse o Projeto

🔗 **Deploy:** https://ttthamenezess.github.io/Petlife-clinica/

🔗 **Repositório:** https://github.com/ttthamenezess/Petlife-clinica

---

## 📌 Visão Geral

O **Petlife Clínica** é uma página web institucional para uma clínica veterinária fictícia.

A página apresenta informações sobre os serviços da clínica, conteúdo visual, seções informativas e uma estrutura simples para apresentar uma marca no ambiente digital.

---

## ⚙️ Funcionalidades

- 🐶 Página institucional para clínica veterinária
- 🐱 Seções informativas sobre serviços
- 🎨 Estilização personalizada com CSS
- 🖼️ Uso de imagens no layout
- ⚡ Interações com JavaScript
- 📄 Página estática simples
